# 灵感抽屉

一个类似 Eagle 的本地设计素材库网页原型，适合用来收集、整理和翻阅设计灵感。

## 直接打开

双击 `index.html`，或用浏览器打开这个文件即可，不需要安装任何东西。

## 现在能做什么

- 用左侧收藏夹筛选素材，文件夹名称可以直接修改
- 可以新建顶层文件夹和子文件夹，也可以删除文件夹
- 在网格和列表两种视图之间切换
- 点击任意素材查看详情、配色和备注
- 鼠标直接点击素材图即可全屏浏览，也可以使用“放大”按钮
- 在右侧直接编辑“案例介绍”
- 素材文件名称也可以直接修改
- 收藏喜欢的素材到“我的收藏”
- 不需要的素材可以直接删除
- 可以进入多选模式，一次勾选多个素材一起删除
- 点击“导入素材”，或直接把图片、视频、PDF 拖进素材墙
- PDF 会自动归入“PDF 文档”收藏夹，卡片里直接显示 PDF 内容，可以放大查看、下载和重命名

## 查看与编辑

- 别人查看：打开 `index.html?view=1`，只能查看和播放，不能修改。
- 自己编辑：直接打开 `index.html`，输入编辑密码后进入编辑模式。
- 默认编辑密码是 `123456`，可以在编辑模式里点击“修改编辑密码”更换。
- 编辑模式里有“复制查看链接”按钮，点一下就能把只读链接发给别人。
